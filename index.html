Acerca del proyecto

Aplicación web para visualizar, ejecutar y comparar los ocho algoritmos de ordenamiento vistos en clase: Selection, Bubble, Insertion, Gnome, Exchange, Stooge, Merge y Quick Sort. Parte de la práctica en Python de la materia y la lleva al navegador.

Equipo Ultima Chance: Johan Daniel Gutierrez Nava.

Tecnologías: HTML, CSS y JavaScript con módulos, sin frameworks; Canvas 2D para las barras, Web Worker para el benchmark y Chart.js para las gráficas.
